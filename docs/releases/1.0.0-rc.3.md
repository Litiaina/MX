# MX 1.0.0-rc.3

[Documentation index](../README.md) · [Updates](../updates.md) · [Changelog](../../CHANGELOG.md)

**Release date:** 2026-10-16 (Asia/Manila).

**Status:** release candidate, not the final stable 1.0.0.

**Rust/frontend version:** `1.0.0-rc.3` · **Tag:** `v1.0.0-rc.3`.

## Changes

Office background preparation waits for a genuine pause in typing, scrolling,
pointer dragging, held keys and text composition. It rechecks interaction after
waiting for local work and spaces repeated exports according to their measured
cost. Opening a large document no longer counts as idle time.

Automatic saves do not accept unfinished spreadsheet input or reselect the
native cell range. Finish the cell with Enter/Tab or select another cell, or
use Ctrl/Cmd+S to explicitly save unfinished input. An explicit save requested
during an automatic upload is remembered and runs afterward for newer edits.
Background feedback stays compact as **Autosaving…**; detailed progress remains
available in the status tooltip and Document options. MX still distinguishes
local recovery from a server-confirmed saved version.

This is not a new Office engine or a real-time collaborative editor. Whole-
document export still occupies the native engine once started and cannot be
safely preempted; expensive exports may briefly delay input. Unfinished cell
input and changes since the last completed checkpoint can still be lost on a
crash. No pause-free export or zero-loss power-cut guarantee is implied.

There is no new database schema migration, N1 storage migration, credential
reset, Office service or runtime application dependency. Existing records,
permissions, Drive objects, file versions and configuration remain in place.
RC.2 sidebar, optional continuous browsing and blank-installation behavior
remain included. Branding assets are unchanged.

## Update an existing managed RC.1/RC.2 deployment

1. Sign in as Administrator and open **Administration → Updates**.
2. Choose **Check for updates**. The deployment must permit the **rc** channel
   and trust the existing publisher key `fdf69f67562fb715`.
3. Confirm `1.0.0-rc.3`, then **Download and verify**.
4. Save open forms and Office documents; calls/transfers are interrupted by
   the restart. Choose **Install now…** when ready, or use your configured
   automatic maintenance window.
5. The independent worker takes and verifies the final SQLite rollback snapshot,
   activates matching native/frontend files and verifies health before reopening
   writes. A failed activation retains the existing paired rollback behavior.
6. After reconnection, confirm RC.3 in Updates. Reload existing Office tabs to
   load the new editor code; save and confirm edits before reloading. Verify an
   Office edit/save and your normal records/Drive workflow.

The same publisher key signs this candidate; operators must not generate a new
trust key or install the publisher private key. Installation policy is unchanged.
Publishing RC.3 does not directly restart MCH or replace the local encoding test.
Deployments configured for automatic installation may discover it and install
it during their maintenance window.

For disconnected deployment, upload the published signed `.mxupdate` through
**Offline update package → Upload and verify**, then use the same worker. New
installations use the matching initial-install archive and
[deployment guide](../deployment.md). Do not replace credentials or reset data.

## Compatibility and qualification

The published target remains Linux x86-64 GNU, glibc 2.39+, OpenSSL 3, zlib,
Zstandard and the standard GCC runtime, as documented for
[RC.1](1.0.0-rc.1.md#release-assets-and-initial-installation).

Validation evidence is recorded in [TESTING.md](../../TESTING.md). Desktop
Chromium, Brave and Firefox exercise real XLSX input and saved contents;
synthetic composition tests do not qualify real OS input methods. Linux WebKit
does not qualify Office editing or real Safari/iOS. Existing complex-document,
real-device media, accessibility, security and physical power-loss acceptance
limits from [RC.1](1.0.0-rc.1.md#not-included-or-not-guaranteed) remain.
